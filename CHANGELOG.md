# Changelog

All notable changes to this template are documented here.
This project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-08-31

Initial release.

### Added
- 13 modules: Dashboard, AI Chat, AI Agents, Prompts, Usage, Billing, Subscription,
  API Keys, Team Members, Roles & Permissions, Analytics, Notifications, Integrations
- 40+ routes including authentication (login, register, password reset, 2FA),
  settings, profile and 404 / 500 error screens
- Light and dark themes driven by CSS custom properties, with a system option
- Collapsible sidebar, command palette (⌘K), notification panel and theme switcher
- Chart kit built on Recharts plus a dependency-free CSS-grid heatmap
- Empty, loading and error states for every data module
- Typed mock data for all entities and an i18n-ready string dictionary
- Documentation (`docs/documentation.html`) and README
